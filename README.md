#Oficina APP - Sistema de Gestão Automotiva

Este projeto é um sistema completo para gerenciamento de oficinas, desenvolvido como Trabalho de Conclusão de Curso (TCC) em Sistemas de Informação. O projeto é dividido em uma API Restful (Back-end) e um aplicativo mobile (Front-end).

##Tecnologias Utilizadas
* **Front-end:** Flutter, Dart
* **Back-end:** Java, Spring Boot, Spring Security, Hibernate/JPA
* **Banco de Dados:** MySQL (via Docker)

## 🚀 Como executar o projeto localmente

### 1. Subindo o Banco de Dados
Certifique-se de ter o [Docker](https://www.docker.com/) instalado. Na raiz do projeto, execute o comando abaixo para iniciar o banco de dados:

```bash
docker-compose up -d
